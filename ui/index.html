            Use webscout from your AI tools

            webscout is also an MCP server, so Claude Code, opencode, pi and other AI assistants can run searches themselves and read the verified results.

            Every client must send the token. It is the value of WEBSCOUT_MCP_TOKEN in the server's .env file; ask whoever runs this server. What you paste here stays in this page and is not saved.
